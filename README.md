# موقع AXIOM+

موقع شبكة كلمة ومركز كلمة للدراسات والبحوث الجيوسياسية، مبنيّ من التصميم المعتمد "كلمة - تصميم الموقع".

يتكوّن المستودع من جزأين:

| الجزء | المجلّد | أين يعمل | وظيفته |
|---|---|---|---|
| الموقع | الجذر (`src/`) | Cloudflare Pages | ما يراه القرّاء على axiomplusmedia.com |
| غرفة التحرير | `studio/` | Cloudflare Pages (مشروع ثانٍ) | لوحة Sanity التي يكتب فيها الفريق ويوافق وينشر |

المحتوى يُحفظ في Sanity. كلّما نشر رئيس التحرير مادّة، يُعاد بناء الموقع تلقائياً خلال دقيقة أو دقيقتين.

---

## مسار الموافقة

| الدور | ما يستطيع |
|---|---|
| **كاتب** | يكتب المسوّدة، ثمّ يضغط "إرسال إلى التحرير". لا يرى زرّ النشر. |
| **محرّر** | يحرّر المادّة، ثمّ إمّا "إعادة إلى الكاتب" مع ملاحظات، وإمّا "انتهى التحرير: رفع إلى رئيس التحرير". لا ينشر. |
| **رئيس التحرير** | وحده يرى زرّ "نشر"، ووحده يحذف المادّة أو يلغي نشرها. |

- كلّ مادّة تحمل شارة بمرحلتها، وسجلّاً بمن نقلها ومتى.
- القائمة الجانبية في غرفة التحرير تبدأ بالطوابير: "بانتظار المحرّر"، "بانتظار رئيس التحرير"، "أُعيدت إلى الكتّاب".
- مدير المشروع في Sanity (أنت) يُعامَل رئيسَ تحرير تلقائياً.
- الأخبار تُنشر باسم الشبكة بلا اسم محرّرها؛ الأسماء تظهر في التحليل والرأي والتحقيق والدراسة فقط.

> **ملاحظة صريحة:** إخفاء زرّ النشر عن الكاتب والمحرّر يتمّ داخل غرفة التحرير. المنع الكامل على مستوى الخادم (حتى لو حاول أحدهم النشر من خارج اللوحة) يحتاج إلى خطّة Sanity المدفوعة التي تتيح دور "Contributor" للكتّاب. في البداية، مع فريق موثوق، الإعداد الحاليّ كافٍ.

## خطوات التشغيل (مرّة واحدة)

### 1. الشعار
ضع ملفّات الشعار المعتمد في `public/brand/` بالأسماء المذكورة في `public/brand/README.txt`. إلى أن تُوضع، يظهر اسم "كلمة" نصّاً مكانها.

### 2. Sanity (غرفة التحرير والمحتوى)
1. ادخل إلى sanity.io وأنشئ حساباً (يمكن الدخول بحساب Google أو GitHub).
2. أنشئ مشروعاً جديداً باسم **AXIOM+**، واختر مجموعة بيانات باسم `production` وظاهرة للعموم (Public).
3. انسخ **Project ID** (رمز من ثمانية أحرف تقريباً): ستحتاجه في الخطوتين 3 و4.

### 3. الموقع على Cloudflare Pages
1. في Cloudflare: Workers & Pages ← Create ← Pages ← Connect to Git، واختر المستودع `axiom-site`.
2. الإعدادات:
   - Framework preset: **Astro**
   - Build command: `npm run build`
   - Build output directory: `dist`
3. Environment variables:
   - `SANITY_PROJECT_ID` = رمز المشروع من الخطوة 2
   - `SANITY_DATASET` = `production`
   - `NODE_VERSION` = `22`
4. Save and Deploy. يظهر الموقع على رابط مؤقّت ينتهي بـ `pages.dev`.

قبل ربط Sanity أو قبل نشر أوّل مادّة، يعرض الموقع القوالب فارغة مع شريط أصفر "نسخة معاينة". يختفي الشريط تلقائياً بعد الربط.

### 4. غرفة التحرير على Cloudflare Pages (مشروع ثانٍ)
1. أنشئ مشروع Pages ثانياً من المستودع نفسه.
2. الإعدادات:
   - Framework preset: None
   - Root directory: `studio`
   - Build command: `npm run build`
   - Build output directory: `dist`
3. Environment variables:
   - `SANITY_STUDIO_PROJECT_ID` = رمز المشروع
   - `SANITY_STUDIO_DATASET` = `production`
   - `NODE_VERSION` = `22`
4. بعد النشر، انسخ رابط غرفة التحرير، ثمّ في sanity.io/manage ← مشروعك ← API ← CORS origins: أضف الرابط وفعّل **Allow credentials**.
5. يُستحسن ربطها لاحقاً بنطاق فرعيّ مثل `studio.axiomplusmedia.com` (وتُضاف هذه أيضاً إلى CORS).

### 5. إعادة البناء التلقائية عند النشر
1. في Cloudflare، مشروع الموقع ← Settings ← Builds ← Deploy hooks ← أنشئ رابطاً باسم "sanity".
2. في sanity.io/manage ← API ← Webhooks ← Create:
   - URL: الرابط الذي أنشأته
   - Trigger on: Create, Update, Delete
   - Filter: `_type in ["article", "writer", "episode", "program", "page", "siteSettings"]`
   - اترك خيار Drafts **غير مفعّل**، حتى لا يُعاد البناء إلا عند النشر.

### 6. الفريق
1. في sanity.io/manage ← Members: ادعُ كلّ عضو ببريده.
2. في غرفة التحرير ← "الكتّاب وفريق التحرير": أنشئ وثيقة لكلّ عضو، واملأ في تبويب "الدور في التحرير" دوره (كاتب، محرّر، رئيس تحرير) والبريد نفسه الذي دُعي به.
3. من لا يريد صفحة عامّة على الموقع (محرّر مثلاً) يُطفأ له خيار "إظهار صفحته على الموقع".

### 7. النطاق axiomplusmedia.com
بعد انتقال النطاق إلى اسمك في Hostinger:
1. أضف النطاق إلى Cloudflare (الخطّة المجانية)، وانسخ خادمَي الأسماء (nameservers) اللذين يعطيك إيّاهما.
2. في Hostinger ← Domains ← النطاق ← DNS / Nameservers: ضع خادمَي Cloudflare بدل خوادم Hostinger.
3. في مشروع الموقع على Cloudflare Pages ← Custom domains: أضف `axiomplusmedia.com` و`www.axiomplusmedia.com`.

> **تنبيه قبل هذه الخطوة:** النطاق يعرض اليوم موقع المركز القديم على ووردبريس. بمجرّد تحويله سيظهر الموقع الجديد ويتوقّف القديم. انقل الدراسات المنشورة هناك إلى غرفة التحرير أوّلاً (أو احتفظ بنسخة كاملة منها). وإن كان للنطاق بريد إلكترونيّ على Hostinger، تأكّد أنّ سجلّات MX انتقلت إلى Cloudflare كما هي.

## ما يقابل كلّ قالب من التصميم

| القالب في التصميم | الرابط على الموقع |
|---|---|
| الصفحة الرئيسية | `/` |
| قالب الخبر | `/news/<الرابط>/` |
| قالب التحليل | `/analysis/<الرابط>/` |
| قالب الرأي | `/opinion/<الرابط>/` |
| قالب التحقيق وخاصّ | `/investigations/<الرابط>/` و`/special/<الرابط>/` |
| قالب الدراسة | `/studies/<الرابط>/` |
| صفحة القسم | `/section/local/` وأخواتها، و`/news/` `/analysis/` `/opinion/`... |
| صفحة الكاتب | `/writers/<الرابط>/` |
| البودكاست والفيديو والنشرة الصوتية | `/media/` و`/media/<الرابط>/` |

إضافةً إلى: البحث `/search/`، والصفحات الثابتة `/page/about/` وأخواتها (تُكتب من غرفة التحرير)، والوضع الداكن والفاتح بزرّ، وصفحة `/en/` مؤقّتة للنسخة الإنكليزية.

## ما بقي لمراحل لاحقة
- **الأكثر قراءة بحسب الزيارات:** حالياً يُختار يدوياً من "إعدادات الموقع"، وإلا تظهر الأحدث. الربط بعدّاد زيارات حقيقيّ خطوة لاحقة.
- **الأسواق والمباريات:** تُدخل يدوياً في "إعدادات الموقع" وتظهر فقط حين تُملأ. الربط بمصدر أسعار ونتائج آليّ خطوة لاحقة.
- **الأخبار الآلية (صحة، رياضة، اقتصاد، فنّ):** تُضاف لاحقاً بحيث تصل مسوّدات إلى طابور المحرّر، ولا يُنشر شيء إلا بقرار بشريّ.
- **النسخة الإنكليزية الكاملة.**
- **النشرة البريدية:** النموذج جاهز ويُرسل إلى `functions/api/subscribe.js`. لحفظ الاشتراكات: أنشئ مخزن KV في Cloudflare باسم SUBSCRIBERS واربطه بمشروع الموقع (Settings ← Functions ← KV namespace bindings).
- **المساحات الإعلانية:** مخفيّة. تُفعَّل بتغيير `showAdSlots` إلى `true` في `src/lib/config.js`.

## للمطوّر
```bash
npm install && npm run dev             # الموقع على localhost:4321
cd studio && npm install && npm run dev  # غرفة التحرير على localhost:3333
```
الإعدادات العامّة (الأقسام، القوائم، روابط الحسابات) في `src/lib/config.js`.
